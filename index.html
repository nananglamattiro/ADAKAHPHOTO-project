Cerita

Kenapa Aplikasi Ini Tercipta?

Semua berawal dari jalanan. 2021 Saat pandemi COVID-19 masih menghantam, ketika banyak orang diam di rumah — saya justru turun ke jalan. Bukan karena tidak takut, tapi karena jalanan adalah tempat saya mencari nafkah halal.

Waktu itu saya foto sport pinggir jalan — momen-momen kecil yang sering terlewat: orang jogging pagi, pengendara motor, pedagang pasar, anak-anak bermain. Semua saya abadikan. Satu per satu, dua per dua, hingga ribuan foto terupload ke galeri tempat penyimpanan foto online.

"Saya bukan orang IT. Saya hanya fotografer jalanan yang capek upload foto manual satu per satu."

Saya bergabung dengan komunitas fotografi: Hunting Pasar Makassar, Fujiners Makassar, InstaMakassar. Di situ saya belajar banyak — tentang komposisi, tentang cahaya, tentang momen. Tapi satu hal yang tidak pernah diajarkan: bagaimana upload ribuan foto dengan cepat.

Setiap event, saya bisa bawa pulang 500-2000 foto. Upload manual satu per satu? Butuh berjam-jam. Belum lagi koneksi yang kadang putus di tengah jalan, atau server yang lambat. Capek. Sangat capek.

2024 — ketika aplikasi penyimpanan foto mulai booming di Indonesia, saya lihat banyak developer membuat tools bantu upload. Tapi kebanyakan:

  • ✗ Berbayar mahal (ratusan ribu per bulan)
  • ✗ Susah dipakai (butuh setting rumit)
  • ✗ Sering error (upload gagal, tidak ada retry)
  • ✗ Tidak cocok untuk Mac lama (2014)

Saya berpikir: "Kenapa tidak saya buat sendiri?"

Saya mulai belajar coding dari nol. Debug sana-sini. Beli Mac bekas 2014 karena budget terbatas. Test upload, gagal, perbaiki, test lagi. Berbulan-bulan. Sampai akhirnya ADAKAHPHOTO-project lahir — aplikasi upload foto yang:

  • ✓ Jalan di Mac lama (2014) — tidak perlu beli Mac baru
  • ✓ Upload 500+ foto per menit — cepat, stabil
  • ✓ Auto-retry kalau gagal — tidak perlu upload manual
  • ✓ Harga terjangkau — mulai Rp 150.000/bulan

Dibuat oleh fotografer, untuk fotografer.
Dari jalanan, untuk jalanan. 🛣️
